# V1完整链路测试记录

## 测试环境

- Spring Boot 3+
- MySQL 8+
- Redis 7+
- Redis Vector

## 测试场景

模拟用户进行多轮企业知识问答，验证系统 RAG 检索能力、短期 Memory 记忆能力以及引用溯源能力。

---

# 第一次请求（测试 RAG 检索能力）

**请求接口：**

POST /api/v1/chat

**输入：**

`Redis有哪些持久化方式？`

**返回结果：**

系统成功召回企业知识库中的 Redis 持久化相关文档。

模型返回：

- RDB 持久化机制
- AOF 持久化机制
- 混合持久化方案

同时 reference 字段正确返回引用信息：

- 文档名称
- 文档 ID
- 页码
- 召回文本片段

**验证内容：**

- 文档向量检索正常
- Redis Vector 召回正常
- RAG 上下文注入正常
- Citation 引用返回正常

**测试结果：**

PASS

---

## 第二次请求（测试 Memory 上下文）

**请求：**

同一 conversationId 下继续提问：
`它们有什么区别？`

**返回结果：**
系统成功结合上一轮对话内容，识别“它们”指代：RDB 和 AOF

并从多个维度进行区别说明：

- 实现原理
- 数据安全性
- 恢复速度
- 文件大小
- 使用场景

**验证内容：**

- conversationId 上下文关联正常
- Redis Memory 历史消息读取正常
- 多轮对话语义理解正常
- 无上下文丢失

**测试结果：**
PASS


---

# 第三次请求（测试无关问题拒答能力）

**请求：**

同一 conversationId 下输入：
`帮我写一个Java小游戏 `  [输入与知识库无关的问题]

**返回结果：**

系统未在当前企业知识库中检索到相关资料。

即系统未生成无依据的回答，同时未返回无关文档引用。

**验证内容：**

- 知识库外问题拒答能力正常
- 未发生大模型幻觉（Hallucination）
- 空引用处理正常

**测试结果：**

PASS
